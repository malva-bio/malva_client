malva_client.cli module¶

malva_client¶

Malva CLI - Search genomic datasets from the command line.

malva_client [OPTIONS] COMMAND [ARGS]...

Options

--version¶

Show the version and exit.

--config <config>¶

Path to configuration file

--server <server>¶

Malva server URL

--token <token>¶

API token for authentication

--no-ssl-verify¶

Disable SSL verification

cell-explorer¶

Build and download per-user metacell cohorts.

malva_client cell-explorer [OPTIONS] COMMAND [ARGS]...

build¶

Build a metacell cohort from metadata filters.

malva_client cell-explorer build [OPTIONS] NAME

Options

--cell-type <cell_types>¶

Cell type filter (repeatable)

--organ <organs>¶

Organ/tissue filter (repeatable)

--disease <diseases>¶

Disease filter (repeatable)

--gene <genes>¶

Gene to include (repeatable)

--dataset <dataset_id>¶

Dataset id

Arguments

NAME¶

Required argument

download¶

Download a cohort Zarr bundle.

malva_client cell-explorer download [OPTIONS] COHORT_ID

Options

-o, --output <output>¶

Output directory or archive path

Arguments

COHORT_ID¶

Required argument

list¶

List your Cell Explorer cohorts.

malva_client cell-explorer list [OPTIONS]

cleanup¶

Clean up old search data

malva_client cleanup [OPTIONS]

Options

--days <days>¶

Days of data to keep

config¶

Manage configuration

malva_client config [OPTIONS]

Options

--key <key>¶

Configuration key to set

--value <value>¶

Configuration value

--server <server>¶

Server URL

--token <token>¶

API token

--show¶

Show current configuration

--reset¶

Reset configuration to defaults

history¶

View search history

malva_client history [OPTIONS]

Options

--limit <limit>¶

Number of searches to show

--export <export>¶

Export history to file

login¶

Interactive login to Malva

malva_client login [OPTIONS]

logout¶

Logout and remove stored credentials

malva_client logout [OPTIONS]

quota¶

Check API quota status

malva_client quota [OPTIONS]

results¶

Get results from previous search

malva_client results [OPTIONS] JOB_ID

Options

-o, --output <output>¶

Output file path

--format <output_format>¶

Output format

Options:

csv | json | excel | table

Arguments

JOB_ID¶

Required argument

search¶

Search genomic datasets.

malva_client search [OPTIONS] QUERY

Options

-o, --output <output>¶

Output file path

--format <output_format>¶

Output format

Options:

csv | json | excel | table

--no-wait¶

Submit search without waiting for completion

--max-wait <max_wait>¶

Maximum time to wait for completion (seconds)

--no-enrich¶

Skip metadata enrichment

-w, --window-size <window_size>¶

Sliding window size (k-mers per window)

-t, --threshold <threshold>¶

Match threshold (0.0-1.0)

--stranded¶

Restrict to single-strand search

Arguments

QUERY¶

Required argument

status¶

Check search status

malva_client status [OPTIONS] JOB_ID

Arguments

JOB_ID¶

Required argument
