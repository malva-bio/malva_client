class malva_client.client.MalvaClient(base_url=None, api_token=None, timeout=300, verify_ssl=True, workspace=None, dataset_id=None, provider_id=None)[source]¶

Bases: object

Main client for interacting with the Malva API

Provides methods for searching, retrieving samples, and downloading data files.

The client prefers canonical API paths and automatically falls back to the historical paths when the server does not expose them. Detection is a one-time authenticated probe of GET /api/account/quota whose result is cached per client; a 200 selects canonical mode and a 404 selects legacy mode. A 401 raises AuthenticationError.

Set MALVA_ENDPOINT_STYLE to canonical, legacy or auto (the default) to override detection. The resolved style is exposed through the read-only endpoint_style property, and reset_endpoint_style() clears a cached auto result.

search(query, wait_for_completion=True, poll_interval=2, max_wait=300, aggregate_expression=True, stranded=None, min_kmer_presence=0, max_kmer_presence=100000, window_size=None, threshold=None)[source]¶

Search by gene name, natural-language description, or DNA sequence.

Parameters:

  • query (str) – Gene symbol ("BRCA1"), comma-separated list of genes ("BRCA1, TP53"), natural-language description ("immune cell marker"), or a DNA sequence string. For multiple sequences or sequences >500 nt, prefer search_sequences().

  • wait_for_completion (bool) – Block until the search finishes. If False, returns immediately with a pending SearchResult whose data is fetched lazily on first .df access.

  • poll_interval (int) – Seconds between status polls (only used when wait_for_completion=True and the job does not complete synchronously).

  • max_wait (int) – Maximum seconds to wait before raising a timeout error.

  • aggregate_expression (bool) – If True (default), returns per-(sample, cell-type) aggregate scores suitable for plotting. If False, returns raw per-cell hit arrays. For downstream cell-level analysis, use retrieve_cells() on the search result.

  • stranded (Optional[bool]) – Strand mode for k-mer matching. True → forward strand only. False → both strands (reverse-complement included). None (default) → server default (currently forward only).

  • min_kmer_presence (int) – Exclude k-mers that appear in fewer than this many cells. Useful to filter out ultra-rare k-mers (noise). Default 0 (no lower filter).

  • max_kmer_presence (int) – Exclude k-mers that appear in more than this many cells. Useful to remove highly repetitive/ubiquitous k-mers. Default 100000.

  • window_size (Optional[int]) – Sliding window size in k-mers. If omitted, the server uses its default.

  • threshold (Optional[float]) – Match threshold between 0.0 and 1.0. If omitted, the server uses its default.

Return type:

SearchResult

Returns:

SearchResult with per-(sample, cell-type) expression aggregates. Access .df to get a pandas DataFrame.

Example:

results = client.search("ACTA2")
print(results.df.head())

# Both strands, excluding very common k-mers
results = client.search("GATTACA" * 10,
                        stranded=False,
                        max_kmer_presence=50000)
retrieve_cells(search_job, features=None, sample_ids=None, include_barcodes=False, include_sample_metadata=True, poll_interval=2, max_wait=300, provider=None)[source]¶

Retrieve positive cells for an existing search job.

Run search() or search_sequences() first, then pass the returned SearchResult or its job_id here. A DataFrame returned by search_federated() is also accepted: the client reads frame.attrs["shards"] and retrieves cells from one completed shard. Pass provider (provider id or name) to choose a specific shard; otherwise the first completed shard with a search job is used. When a provider is selected, its id is forwarded as ?provider= to every search-service call used for retrieval, and the local values export is skipped. This method does not start a new search and does not use the ZIP export workflow. The client first asks the search service for per-feature cell/sample/expression arrays so the value column contains raw per-cell expression/k-mer counts when available. The fast global cell-ID endpoint is used only as a fallback; it cannot carry per-cell expression values and therefore reports positive-cell indicators.

Return type:

CellExpressionMatrixResult

Search for one or more DNA sequences.

Accepts either a single sequence string or a list of sequences. Multiple sequences are submitted as a single FASTA batch request (only one search quota slot consumed).

Parameters:

    A single DNA sequence string or a list of DNA sequence strings.

    • Single string: up to 500,000 nt.

    • List: each entry up to 500,000 nt; total across all sequences must not exceed 100,000 nt.

    Valid nucleotide characters: A, T, G, C, U, N (case-insensitive).

  • wait_for_completion (bool) – Block until the search finishes.

  • poll_interval (int) – Seconds between status polls.

  • max_wait (int) – Maximum seconds to wait before raising a timeout error.

  • aggregate_expression (bool) – If True (default), returns per-(sample, cell-type) aggregate scores. For downstream cell-level analysis, use retrieve_cells() on the search result.

  • stranded (Optional[bool]) – Strand mode for k-mer matching. True → forward strand only. False → both strands (reverse-complement included). None (default) → server default (currently forward only).

  • min_kmer_presence (int) – Exclude k-mers that appear in fewer than this many cells. Default 0 (no lower filter).

  • max_kmer_presence (int) – Exclude k-mers that appear in more than this many cells. Default 100000.

Return type:

SearchResult

Returns:

SearchResult with per-(sample, cell-type) aggregates.

Examples:

search_federated(query, provider_ids=None, dataset_id=None, poll_interval=2, max_wait=300, strict=False)[source]¶

Search every configured Explorer provider and keep the origin.

This calls the Explorer’s federated endpoints, not the monorepo /search endpoint. The returned DataFrame has provider and provider_id as its first two columns, followed by the usual expression columns.

Provenance is always attached to df.attrs:

  • job_id: federated job id

  • status: final aggregate status reported by the Explorer

  • shards: final per-provider shard dictionaries

  • providers: concise per-provider metadata (id, name, status, error)

  • errors: human-readable per-provider errors

  • shard_errors: the same errors as structured dictionaries

Failed shards are never silently dropped: they emit a warning and are listed in attrs["errors"]. Pass strict=True to raise instead.

Parameters:

  • query (str) – Gene symbol, description, or DNA sequence.

  • provider_ids (Optional[List[str]]) – Optional provider ids to search. When omitted, the default list is resolved from the provider ids advertised by get_workspace(). If that lookup fails or the workspace advertises no providers, the field is omitted. Explicit ids always take precedence and are validated against get_workspace() before submitting.

  • dataset_id (Optional[str]) – Search index for this call. Defaults to the client’s configured dataset_id.

  • poll_interval (int) – Seconds between federated status polls.

  • max_wait (int) – Maximum seconds to wait for all shards.

  • strict (bool) – Raise MalvaAPIError if any shard failed, even when other shards returned rows.

Return type:

DataFrame

Returns:

A pandas DataFrame with one row per provider, sample and cell type. Empty successful searches still carry the declared schema and provenance.

Raises:

MalvaAPIError – If every shard failed, a requested provider is unknown, any shard failed while strict=True, or the job timed out (including a zero-shard job that never finishes).

stream_cell_expression(sample_ids=None, gene_ids=None, dataset_id=None, max_batch_bytes=4194304, chunk_size=65536, cells=None)[source]¶

Stream sparse per-cell expression batches for selected samples.

By default this returns a CellExpressionStream that yields one pandas DataFrame per server batch, exactly like the previous generator API:

for batch in client.stream_cell_expression(
    sample_ids=[30064771072],
    gene_ids=["CD3D", "CD3E", "CD247"],
    dataset_id="Human_Cell_Atlas",
):
    print(batch.head())

DataFrames contain sample_id, cell_id, store_index, gene and value. Only non-zero values are returned; absent (sample_id, cell_id, gene) combinations are zero. Passing gene_ids is strongly recommended: without it the server must scan every non-zero entry in the selected petal stores.

The wrapper also provides to_anndata(), write_h5ad(path) and iter_anndata() for standard AnnData workflows.

Return type:

CellExpressionStream

find_metacells(adata, groupby, top_n=50, dataset_id=None, *, layer=None, feature_ids=None, method='cosine', sample_metadata=None)[source]¶

Find Malva atlas metacells that look most like each local cluster.

The AnnData object stays local: clusters are averaged into pseudobulk profiles and only those few cluster × gene vectors are sent to Malva.

Parameters:

  • adata – AnnData object with cells in obs and genes in var.

  • groupby (str) – Categorical adata.obs column defining the clusters.

  • top_n (int) – Number of metacell neighbours per cluster (1–1000, default 50).

  • dataset_id (Optional[str]) – Malva dataset / coexpression index identifier.

  • layer (Optional[str]) – Optional adata.layers key to use instead of adata.X.

  • feature_ids (Optional[Iterable[str]]) – Optional Malva feature IDs aligned to adata.var_names. Defaults to adata.var_names.

  • method (str) – Scoring space. "cosine" (default) preserves the legacy full-gene raw-mean cosine. "hellinger" uses Bhattacharyya cosine on a variable-gene composition panel; "panel_lda" uses a between/within-type weighted panel cosine. The new spaces also return per-cell-type top-k scores used by MetacellMatchResult.assign_labels().

  • sample_metadata (Union[DataFrame, Dict[Any, Any], None]) – Optional local sample metadata (DataFrame indexed by sample_id, or a mapping sample_id -> row). It is merged locally after the response; no metadata is requested from Malva.

Return type:

MetacellMatchResult

Returns:

MetacellMatchResult, a DataFrame-like object with to_dataframe(), enrich() and assign_labels(). Its columns are cluster, rank, metacell_id, sample_id, cell_type, n_cells, similarity, distance, and enrichment_score (plus any local sample metadata columns).

Build a per-user metacell cohort and its Zarr store.

Filters are applied at the same (sample × cell type) metacell level the search engine uses. The cohort is also registered as an analysis cell group, so it can be used by the existing analysis widgets.

cohort = client.create_cell_explorer_cohort(

    cell_types=["alveolar macrophage"],
    organs=["lung"],
    diseases=["idiopathic pulmonary fibrosis"],
    genes=["SPP1", "TREM2"],
