SearchResult¶

class malva_client.models.SearchResult(raw_data, client)[source]¶

Bases: MalvaDataFrame

Container for search results that extends MalvaDataFrame for direct analysis.

Data loading is lazy: if raw_data contains no ‘results’ (e.g. it is the initial POST response or a lightweight status response), the DataFrame is populated on first access to .df by fetching the job results endpoint (canonical /api/search/<job_id>/results or legacy /api/expression-data/<job_id>/results) from the server.

enrich(sample_metadata=None)[source]¶

Attach sample metadata to the result and return self.

Metadata already available locally is reused. Only sample IDs that are still missing are requested from Malva, so calling enrich() again is cheap. This method is metadata-only: it never runs GO or cell-type enrichment.

to_anndata()[source]¶

Materialise the aggregated search result as a sample × cell-type AnnData.

Observations are unique sample_id × cell_type pairs, variables are genes (gene_sequence), and X is a sparse float32 matrix of relative normalized expression (rel). Sample metadata is included in obs when available and provenance is stored in uns['malva'].

Iterable wrapper around a server cell-expression stream.

Iterating the object yields the same pandas DataFrames as before: one frame per server batch with sample_id, cell_id, store_index, gene and value columns. The convenience methods materialise those batches as standard AnnData objects.

write_h5ad(path)[source]¶

Write the stream to path with bounded memory.

The stream is spooled to a temporary SQLite database, then assembled in cell chunks of at most cell_chunk_size observations. Only one chunk is held in memory at a time. Read the result lazily with anndata.read_h5ad(path, backed="r").

assign_labels(adata=None, groupby=None, *, column='malva_cell_type', confidence_column=None, weight='auto', write_to_obs=True)[source]¶

Assign one Malva cell-type label per local cluster.

With the new method="hellinger" / "panel_lda" spaces the server returns per-cell-type top-k scores. weight="auto" (the default) uses those scores when present and falls back to the legacy similarity sum for raw-cosine results. Pass weight="similarity" or weight="rank" to force the legacy neighbour aggregation. Confidence is the winning share of the positive scores/weights.

When adata is supplied (and write_to_obs is true), the labels are written to adata.obs[column].

Return type:

DataFrame
